## База даних `mlflow` 
База даних `mlflow` створюється автоматично за допомогою ініціалізаційного скрипта `docker-entrypoint-initdb.d/init-mlflow.sql`. 
Цей скрипт виконується PostgreSQL лише один раз під час створення порожнього тому даних (`pgdata`). Якщо том даних вже був ініціалізований раніше, автоматичне створення БД не відбудеться. У такому випадку потрібно виконати наступну команду вручну всередині контейнера БД: `docker compose exec postgres psql -U orders -c "CREATE DATABASE mlflow;"`

## Обґрунтування публікації порту MLflow
Порт інтерфейсу користувача (UI) MLflow (5000) опубліковано на хост-машині. Це не порушує принцип "єдиної зовнішньої точки входу", оскільки MLflow UI є виключно внутрішнім інструментом моніторингу та керування. Він не є клієнтським API і не бере участі в обробці запитів користувачів.
